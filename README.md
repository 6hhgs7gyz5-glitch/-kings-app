# KINGS — correção definitiva do Caixa

- Saídas de caixa entram no total de Saídas.
- Saldo = Entradas - Saídas.
- Compatível com registros antigos que usem `value`, `price`, `amount` ou `valor`.
- Caixa possui filtros Hoje, 7 dias, Mês e Tudo.
- Atualização com marcador de build para evitar cache antigo.
