# KINGS — Gestão da Barbearia
Versão 3.0 preparada para GitHub Pages.

Inclui:
- logo oficial KINGS enviada pelo proprietário
- saída de caixa e despesas
- saldo líquido
- relatórios com gráfico
- metas diária e mensal
- Pix, dinheiro, cartão e fiado
- horário do corte e barbeiro
- edição/exclusão de clientes
- funcionamento offline via Service Worker
- PWA para iPhone

Para atualizar o app existente, substitua os arquivos do repositório pela versão deste pacote e faça commit diretamente na branch principal.
